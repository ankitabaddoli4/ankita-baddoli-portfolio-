HOW TO RUN THE WEBSITE LOCALLY
------------------------------------------------------------

1. Download or clone the portfolio project.

2. Extract the ZIP file if it is downloaded as a ZIP.

3. Open the portfolio folder in Visual Studio Code.

4. Make sure these files are in the same folder:

   index.html
   style.css
   script.js
   README.txt

5. Open index.html.

6. You can simply open index.html in your browser.

Recommended:

Use the Live Server extension in Visual Studio Code.

Steps:

- Install the "Live Server" extension.
- Right-click index.html.
- Select "Open with Live Server".

The website will open at an address similar to:

http://127.0.0.1:5500/index.html
